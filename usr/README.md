# Aero Pomoćnik

Jednostavna i korisna mobilna aplikacija namenjena početnicima u elektronici i aero modelarstvu. Aplikacija omogućava brzo računanje ključnih parametara i organizaciju opreme na jednom mestu.

## Mogućnosti aplikacije
- **Kalkulator za Omov zakon**: Brzo izračunajte jačinu struje (Amperi) na osnovu unetog napona (Volti) i otpora (Omi).
- **Kalkulator težišta (CG)**: Odredite idealnu tačku ravnoteže za vaš RC model aviona (postavljeno na standardnih 30% od širine krila).
- **Spisak delova**: Jednostavan inventar za upisivanje i organizovanje vaših delova za modelarstvo (motori, servoi, baterije, itd.).

## Tehnologije
- Flutter (Dart) - Prilagodljiv korisnički interfejs koji podržava rad na mobilnim telefonima, tabletima, pa čak i unutar web pregledača.

## Pokretanje aplikacije
Da biste pokrenuli aplikaciju na svom uređaju ili u pregledaču:
1. Klonirajte ovaj repozitorijum.
2. Uverite se da je Flutter instaliran (`flutter doctor`).
3. Pokrenite aplikaciju komandom:
   ```bash
   flutter run
   ```
